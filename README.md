# MovieExplorer

A simple React app to browse and search movies/TV shows using the TVMaze API.

## Features
- Home page with hero banner
- Movie listing page with search
- Movie details modal
- Responsive design (mobile + desktop)

## Tech Stack
- React (Vite)
- React Router
- Tailwind CSS
- TVMaze API

## How to run

1. Install dependencies:
```
npm install
```

2. Start the dev server:
```
npm run dev
```

3. Open the link shown in the terminal (usually http://localhost:5173)

## API used
- All shows: https://api.tvmaze.com/shows
- Search shows: https://api.tvmaze.com/search/shows?q=QUERY
